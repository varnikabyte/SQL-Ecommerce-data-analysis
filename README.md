A SQL project analyzing e-commerce sales data to derive business insights around inventory, revenue, and customer behavior.

## What it does
- Sets up database schema and imports raw e-commerce data
- Writes SQL queries to analyze sales trends, inventory levels, and revenue
- Uses joins, aggregations, and filtering to answer business questions

## Tech Stack
- SQL (MySQL)

## How to run
1. Clone this repo
2. Import the dataset into MySQL Workbench 
3. Run the queries in queries.sql to reproduce the analysis
